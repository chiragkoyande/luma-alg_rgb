Checking hardware

Why per-key is not live yet

Acer’s Windows per-key stack talks to HID 048D:8910 (an ITE 829x controller). Linux currently enumerates only the touchpad on the HID bus, not that keyboard controller. The CLV0001 ACPI path used by this app is zone RGB: it can color the keyboard, light bar and logo, but it does not address individual keys.
